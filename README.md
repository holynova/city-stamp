# 城市印记 · City Stamp

把走过的地标，收进会发光的六边形徽章。

上海、苏州、北京、杭州各 10 个地标，共 40 枚。灰阶徽章点击后变色发光并记时；支持城市切换、筛选、悬浮视差、全屏 3D 详情、可缩放六边形打卡墙与带进度的分享卡片。本地保存数据。
